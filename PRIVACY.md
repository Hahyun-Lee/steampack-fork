# Privacy

SteamPack processes power, battery, and thermal state locally on the Mac.

It does not collect telemetry or analytics, create an account, contact a network service, store an administrator password, or transmit user data. Local state files contain requested and applied Boolean control state, a control revision and timestamp, the applied-state update time used to expire stale Control Center state, and crash-recovery ownership metadata: a random lease token, owner process ID, lease creation time, and owner process start time.
